01

Project Overview

The HR Analytics Dashboard is a two-page Tableau workbook built on top of a single employee-level dataset. It gives HR and business stakeholders a way to monitor headcount, hiring and attrition trends, workforce demographics, and pay equity at a glance, and gives HR operations a searchable, filterable record of every individual employee.

The workbook is deliberately split by use case: a high-level Overview page for trend-spotting and reporting, and a row-level Employee Details page for lookups, audits, and exports.

Primary audience

  • HR leadership & business stakeholders — workforce trends, attrition, pay equity
  • HR operations / people analytics — individual employee lookups and exports

What this document covers

  • Data source and grain
  • Navigation and every visual element on both pages
  • Every calculated field, with formula and intent
  • Full dimension/measure dictionary and open items to confirm
02

Data Source & Model

The workbook connects to a single flat file, dataset.csv, confirmed by the auto-generated dataset.csv (Count) measure in the data pane. There is no evidence of a secondary table or blend in the current view — every dimension and measure resolves against one employee-level extract.

Grain

One row per employee. Employee ID is the natural key.

Core dimensions

  • Identity: Employee ID, First Name, Last Name, Full Name
  • Demographics: Gender, Birthdate, Age Group, Education Level
  • Role: Department → Job Title (hierarchy)
  • Geography: Location → State → City (hierarchy), plus generated Latitude/Longitude
  • Employment lifecycle: Hiredate, Termdate, Status, Performance Rating

Core measures

Salary (raw), plus a set of calculated measures (Total Active, Total Hired, Total Terminated, Age, Length of Hire, and three ranking/highlight flags) detailed in Section 06.

Note — This documentation describes the model as observed from the published data pane and dashboard screenshots. If the underlying workbook later adds a second data source, relationship, or extract refresh schedule, this section should be updated to match.

Dashboard Navigation

The workbook has exactly two dashboards, reached from icon buttons in the persistent left-hand rail:

  • Bar-chart iconOpens the Overview page — KPIs, trends, demographics, and pay.
  • Table iconOpens the Employee Details page — the full, filterable employee list.
  • Info (i)Workbook / author information panel.
  • Export — PDFDownloads the current dashboard view as a PDF.
  • Export — ImageDownloads the current dashboard view as an image.
  • Follow / social iconsLinks out to the author's profile pages (LinkedIn, GitHub, and a third profile link).

08

Interactivity & Actions

  • Global quick filters (Overview) — Gender, Location, Status, Hiredate; shown or hidden as a group via the Filter toggle switch.
  • Click-to-filter containers (Overview) — the Overview, Demographics, and Income section headers carry "Click Here To Filter" hints, indicating a Tableau dashboard filter action fires when a mark inside that container is clicked.
  • Expandable column filters (Employee Details) — each of the seven header groups (ID, Demographics, Role, Geographics, Salary, Status, Length of Employment) expands via its arrow icon to reveal native quick filters for that group's fields.
  • Shared status legend — the Hired/Terminated dot legend (top-right on both pages) is visually consistent and may double as a highlighter; confirm in the workbook whether it's wired as a Tableau Highlight Action.
  • Export controls — PDF and Image export buttons in the left rail, standard Tableau dashboard downloads.
09

Design System

The dashboard itself (not this document) runs a dark theme with a two-colour semantic palette carried through every chart, badge, and legend:

TokenApprox. valueUsed for
Background#14171C–ish near-blackPage and card backgrounds
Teal≈ #1FBF9CHired / Active / positive values, primary emphasis
Pink / magenta≈ #E8368FTerminated / negative values
Neutral greymid-grey"All" filter states, inactive markers

Tenure pills on the Employee Details table reuse the teal token regardless of duration; the HQ/Branch and donut charts reuse the same two-colour logic rather than introducing new hues. Keeping any future additions to this two-colour system (plus neutral grey) will preserve the existing visual language.
